# Week 33 — Challenges

The exercises get a robot into each sim and give you a measurement tool. **The challenge is the syllabus lab:** run the *identical* patrol behavior in both simulators (or two Gz engines on Path B) and write the comparison a senior engineer would defend in a design review.

## Index

1. **[Challenge 1 — Same robot, same patrol, two sims](./challenge-01-same-robot-two-sims.md)** — run one behavior tree in Gz Sim and Isaac Sim (Path A) or under two Gz engines (Path B), capture RTF / step-time / sensor fidelity / contact behavior with the Exercise-2 node, and produce the one-page sim-selection write-up. (~2–3 h)

Challenges are optional for passing the week, but this one *is* the week's deliverable — the syllabus says "run the same patrol BT in each; compare contact behavior, sensor fidelity, and step-time; one-page write-up." The skill it builds — comparing tools fairly and choosing per purpose with the trade written down — is exactly what you'll do for real the first time your team argues "Gz or Isaac?" in a planning meeting. The engineer who shows up with a measured table ends that argument in five minutes.
